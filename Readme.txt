====================================
       GoWR No-Clip Tool
====================================
------------------------------------
              FEATURES
------------------------------------

- [W][A][S][D] → Move Kratos freely in space
- [Q][E]       → Move up / down vertically
- [G]          → Toggle No-Clip Mode (enable/disable movement injection)
- [L]          → Lock gravity (no falling)
- [U]          → Unlock gravity (restore normal gravity)
- Target height locking (hover at a fixed height)
- CLI command support (type commands manually)
- Thread-safe atomic control logic

------------------------------------
         CONSOLE COMMANDS
------------------------------------

You can also type these commands directly in the console window:

    w / s / a / d    → Move instantly in direction
    q / e            → Adjust vertical position
    l / u            → Lock/unlock gravity
    x                → Exit the tool
